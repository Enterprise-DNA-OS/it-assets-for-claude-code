# Why the database comes first

Custody, dates, installations and disposal evidence are records. A trusted operator can ask an agent to query and update those records through a tested CLI. Read-only HTML gives the weekly overview, handover paperwork and stocktake list without another application to maintain.

A dedicated screen adds mobile scanning, offline capture, employee acknowledgements, drag and drop, roles and concurrent self-service. This base supplies none of those. It also does not discover endpoints, enforce device policy, scan vulnerabilities, install software, wipe disks or send reminders. Choose it for the register and operator review workflow. Enterprise DNA can build the additional screens and connections you need.

Local reports can become stale immediately after a record changes. Regenerate them and protect their files. The report timestamp is the generation time, not proof that a device was physically checked. A human observation, with evidence, supplies that date.
